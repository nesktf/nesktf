Hello, I'm nesktf. I'm some random guy who likes programming fun things.

I like to do projects in low level languages like C and C++. My favorite kind of projects are usually those related to game engines or embedded systems, some examples are:
- [ranmath](https://github.com/nesktf/ranmath): A linear algebra library that is similar to GLM.
- [ntfstl](https://github.com/nesktf/ntfstl): General STL like templates for my projects.
- [kappa_engine](https://github.com/nesktf/kappa_engine): An eternal WIP 3D game engine made with Vulkan.
- [danmaku_engine](https://github.com/nesktf/danmaku_engine): Another eternal WIP game engine for STG touhou like games with Lua scripts.
- [mikugl](https://github.com/nesktf/mikugl): Model visualizer for MikuMikuDance models for Linux, made with OpenGL.
- [lora_gps_tracking](https://github.com/nesktf/lora_gps_tracking): Tracking system for car GPS coordinates based on a NodeMCU ESP8266.

From time to time I also do some webdev or UI focused software, some examples are:
- [güemaps](https://github.com/nesktf/guemaps): An android app for tracking bus GPS coordinates in my home town.
- [policonsultiro_devforce](https://github.com/nesktf/policonsultorio_devforce): ERP system for a clinic that i've worked on in an agile group setting.
- [chenga_store](https://github.com/nesktf/chenga_store): A simple and funny e-commerce system for a manga store.


Sometimes i like writing about random thoughts and projects on my blog at [nesktf.neocities.org](https://nesktf.neocities.org/), if you are into reading that kind of thing.
